# CustomPerm 2.0.1

**Compatibility:** Minecraft 1.21.1 · NeoForge 21.1.221+ · Java 21 · LuckPerms 5.4.150+ (optional) · Arcadia Lib 1.3.0+ (cluster mode only)

License and links update. Nothing changes in game, in the configuration or in the permission nodes: replacing the 2.0.0 jar is all there is to do.

---

## Licence

2.0.1 ships under license 3.0, closed-source: the source code is no longer published. Running the mod on your server and including it in a CurseForge or Modrinth modpack that fetches the unmodified official file stay allowed, exactly as before; anything else needs written permission. Releases already published keep the licence they shipped with. See the [licence](https://github.com/THEFricadelle/mc-mods-issues/blob/main/licenses/customperm/LICENSE) and its [plain-language summary](https://github.com/THEFricadelle/mc-mods-issues/blob/main/licenses/customperm/NOTICE.md).

The contributor credits now ship inside the jar, in `META-INF/CONTRIBUTORS.md`.

---

## Reporting an issue

Use the [bug report form](https://github.com/THEFricadelle/mc-mods-issues/issues/new?template=bug-customperm.yml), which asks for your server type (dedicated or singleplayer), your LuckPerms version if any and the relevant lines of `logs/latest.log`; say whether cluster mode is on. The issue link of the mod list opens the same form. For anything the licence does not already allow, [ask for a permission](https://github.com/THEFricadelle/mc-mods-issues/issues/new?template=permission-request.yml).
