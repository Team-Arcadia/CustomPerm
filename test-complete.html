Préparation initiale

Avant de commencer :
  1. Stoppe l'éventuel serveur en cours (stop dans la fenêtre PowerShell).
  2. Vérifie que run\mods\ contient le jar LuckPerms (ex: LuckPerms-NeoForge-5.4.150.jar).
  3. Optionnel mais conseillé : reset le monde pour repartir propre.
Remove-Item "run\world" -Recurse -Force -ErrorAction SilentlyContinue
.\gradlew.bat runServer

Une fois le serveur démarré, ouvre une 2e PowerShell et lance le client :

cd "C:\Users\thefr\Desktop\Mods\CustomPerm"
.\gradlew.bat runClient

Connecte-toi sur 127.0.0.1.

Transition vers le mode Internal (sans LuckPerms)

  1. Dans la console serveur, tape stop.
  2. Dans une PowerShell, déplace le jar LP hors du dossier mods : 
    Move-Item "run\mods\LuckPerms-NeoForge-*.jar" "run\"
  3. Optionnel : reset les configs pour repartir propre : 
    Remove-Item "run\config\customperm" -Recurse -Force -ErrorAction SilentlyContinue
  4. Relance le serveur : 
    .\gradlew.bat runServer
  5. Reconnecte le client (127.0.0.1).
